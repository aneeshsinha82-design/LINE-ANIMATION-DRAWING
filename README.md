# Line Drawing Animator

Upload line drawings and watch one continuous pen line trace each of them, with colour blobs, typed text and a panning camera over paper texture.

## Put it online (GitHub Pages)
1. Upload `index.html` and `README.md` to the root of your repo.
2. Repo **Settings → Pages → Deploy from a branch → `main` / root → Save**.
3. Open `https://<your-username>.github.io/LINE-ANIMATION-DRAWING/`.

## Use it
1. Drop your drawings in (they animate in the order listed).
2. Per drawing: set the title, body text, blob colour and which side the text sits on.
3. Press Play, choose 720p, 1080p HD or 4K and press **Export MP4**.

## Drawings that work best
Dark single-weight lines on a plain white or light background, PNG or JPG, at least 800 px wide, one subject per image, with no shading or fills.
